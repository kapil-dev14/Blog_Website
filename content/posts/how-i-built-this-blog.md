This site is built with **Next.js App Router**, Markdown for content, and **Supabase** for likes and comments.

## The stack

- Next.js for rendering and routing
- Markdown files for post content
- Supabase (Postgres) for likes & comments
- Tailwind CSS for styling
- Lucide for icons
- Sonner for toast notifications

Simple, fast, and fully under my control.
